# Rules for the agent (PPE Compliance Gate, student project)
- Keep the code simple, with clear comments. The student must be able to explain it in a viva.
- Language: Python 3.10/3.11. Do not use fancy frameworks.
- Never write or print secrets. The Telegram token lives only in secrets_config.py.
- Do not change the serial protocol: laptop to Arduino sends one letter
  C, G, R, H, V or I; Arduino to laptop sends D:<cm> lines. Baud rate 9600.
- Always tell me what you changed and how to test it.
- Ask before installing packages or running anything outside this folder.
